# 工作流 07 · 沟通话术顾问

- **一句话用途**：把「得罪人的话」翻译成「让人愿意配合的话」。
- **适用场景**：催材料、拒绝不合理请求、调解同学矛盾、向辅导员汇报难题、应对群聊冲突。
- **输入**：场景描述 + 对方态度 + 你的目标。
- **输出**：3 档话术（软/中/硬）+ 使用时机 + 兜底方案。

## 提示词模板（复制即用）

```
你是班级沟通顾问。场景如下：
- 我要做的事：【如：催 5 位同学明天前交体检表】
- 对方反应：【已提醒 2 次，有人已读不回，有人嫌烦】
- 我的目标：【不伤关系、按时收齐、必要时能上报老师】
- 我的身份：班长，与同学平级

请给出：
1. 软/中/硬三档话术（各 ≤60 字）；
2. 每档什么时候用；
3. 若仍然不配合，向上汇报的模板（保留提醒记录的语气）；
4. 一条「群公告式」统一催交通知（不点名）。
```

## 使用示例：调解矛盾

我要做的事：两位室友因作息冲突在群里互相指责；目标：降温、私下解决、不升级到辅导员。

## 注意
- 话术是工具不是套路：最终靠真诚与实际行动，模板只帮你把话说得体。
- 涉及人身安全、欺凌、财务纠纷时不要自己调解，第一时间上报辅导员。
