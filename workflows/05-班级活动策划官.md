# 工作流 05 · 班级活动策划官

- **一句话用途**：5 分钟产出一份能直接执行的班级活动方案。
- **适用场景**：破冰、生日会、中秋活动、操场夜跑、读书会、志愿活动。
- **输入**：活动主题 + 预算 + 人数 + 时长 + 地点条件。
- **输出**：完整方案（流程/分工/物资/预算/风险）+ 群公告 + 报名接龙模板。

## 提示词模板（复制即用）

```
你是班级活动策划。请按下列条件设计班级活动：
- 主题：【如：军训结束破冰会】
- 人数：全班【XX】人
- 时长：【2 小时】
- 预算：人均【10 元】
- 场地：【教室/操场，条件有限】
- 特殊要求：不冷场、低风险、人人可参与、有拍照环节

请输出：
1. 活动名称 + 一句话主题；
2. 时间流程表（每 15 分钟一段，含主持人串词要点）；
3. 分工表（谁管签到/物资/摄影/气氛）；
4. 物资与预算明细；
5. 风险与预案（下雨/冷场/有人受伤/临时缺席）；
6. 群公告 + 报名接龙模板；
7. 活动后复盘问题清单。
```

## 注意
- 涉及费用的活动：金额必须班委讨论 + 辅导员知情，AI 给的预算只作参考。
- 户外/夜间活动风险自担，优先选校内场地。
