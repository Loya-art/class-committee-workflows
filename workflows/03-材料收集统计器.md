# 工作流 03 · 材料收集统计器

- **一句话用途**：把接龙、问卷、Excel 原始数据整理成「已交/未交」名单表。
- **适用场景**：收军训照片、一寸照、体检表、登记表、班费等。
- **输入**：原始名单（全表）+ 收集记录（接龙文字/问卷导出/勾选截图文字）。
- **输出**：未交名单 + 汇总表 + 催交通知 + 核对口径。

## 提示词模板（复制即用）

```
你是班级事务的数据助手。我有两份数据：
A. 全班名单：【粘贴名单，建议已脱敏】
B. 收集记录：【粘贴接龙文字 / 问卷结果 / 已交记录】

请：
1. 生成「未交名单」，只列未出现/未勾选的人，按宿舍或学号排序。
2. 生成「已交汇总表」：人数、缺失类型、异常项（重名、格式错误、缺材料）。
3. 给一条群公告催交通知 + 一条私下催交话术。
4. 输出核对口径：我该怎么复查？（例如：按「姓名+学号后四位」去重）
```

## 输出示例

**未交名单（3 人）**：同学 C（缺一寸照）、同学 F（照片格式不对）、同学 G（完全未交）

## 注意
- **大名单隐私红线**：把全班姓名+学号原文发给在线 AI 前先脱敏（学号只留后四位、姓名可用编号），或用本地模型/表格公式（COUNTIF/VLOOKUP）代替。
- AI 做的是「初筛」，最后提交前必须人工核对一遍总数。
