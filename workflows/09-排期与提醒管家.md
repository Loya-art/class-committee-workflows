# 工作流 09 · 排期与提醒管家

- **一句话用途**：把一堆截止时间变成「提前提醒 + 不撞车」的排期表。
- **适用场景**：开学季/军训季通知密集期、班会与活动排期、班委值班表。
- **输入**：截止时间清单 + 你的可用时段。
- **输出**：时间轴排期 + 提醒计划 + 冲突项标记。

## 提示词模板（复制即用）

```
你是班长的时间管家。以下是我的事项清单（事项/截止时间/负责人）：
【粘贴清单】

请：
1. 按截止时间排序生成时间轴，标出「今天/明天/本周」三级；
2. 为每个事项设计提醒计划（提前 3 天、1 天、当天早上）；
3. 找出冲突（同一时段两个活动、同一天多个材料截止），给出调整建议；
4. 把我的「班务时间」安排成每晚固定一个时段，并给出拒绝超时的说法。
```

## 注意
- 提醒发 3 次是「尽责」，发 10 次是「打扰」：3 天/1 天/当天早上即可。
- 自己也要被提醒：把 AI 输出的时间轴导进手机日历。
