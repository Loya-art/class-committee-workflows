# 工作流 02 · 群公告生成器

- **一句话用途**：把长通知变成同学愿意看、看得懂的 3 行群公告。
- **适用场景**：转发学校/学院长通知、第二天军训安排、交材料提醒。
- **输入**：长通知原文 + 可选语气（轻松/正式）。
- **输出**：3 行公告 + 行动项 + 追问话术。

## 提示词模板（复制即用）

```
你是高校班级群的公告编辑。请把下面的长通知改写成班群公告，要求：
1. 结构 3 行：① 是什么事（一句话）；② 要做什么/带什么/何时何地；③ 截止与联系谁。
2. 重点用【】或加粗标出；语气友好，不命令式。
3. 末尾加「有问题随时私聊我」。
4. 如果通知里有容易看漏的细节（时间、地点、材料份数），单独列「容易漏的 3 个点」。
5. 同时生成一个「48 小时后二次提醒」版本，短一点。

长通知原文：
【粘贴】
```

## 输出示例

⏰【明天军训】6:30 集合 · 穿全套迷彩 · 带水杯
📍 集合点：东区田径场门口，迟到按纪律处理
⚠️ 今晚 22:30 前把【一寸照 ×2】交给我，还差：王、李、张
——有问题随时私聊我

## 注意
- 转发官方通知时：公告里保留「以官方原文为准」字样，防止转述失真背锅。
- 金额、时间、地点三类信息必须逐字核对，AI 最容易在这三处出错。
