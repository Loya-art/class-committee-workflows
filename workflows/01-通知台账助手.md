# 工作流 01 · 通知台账助手

- **一句话用途**：把辅导员/老师的杂乱通知，变成一张「谁、什么事、何时截止、交到哪、谁跟进」的台账。
- **适用场景**：收到任何一条通知，第一时间跑一遍；每天晚上花 3 分钟清空当天积压。
- **输入**：原始通知原文（文字/图片/截图文字）。
- **输出**：结构化台账行 + 待办提醒 + 可直接发群的浓缩版。

## 提示词模板（复制即用）

```
你是一名高校班级的班长助理。请把下面这条通知转成「通知台账」，要求：
1. 提取字段：事项名称、发布来源（学院/教务/辅导员/教官）、截止时间、执行对象、交付方式、负责人、优先级（高/中/低）、备注。
2. 用 Markdown 表格输出。
3. 在表格下方列出：
   - 「今日必做」：24 小时内必须处理的动作；
   - 「群公告 3 行版」：压缩成 3 行、重点标粗的班群公告；
   - 「催交话术」：若涉及收材料，给一条友好催交文案。
4. 若通知信息不完整（缺截止时间/地点/对象），单独列出「待确认问题清单」，我拿去问老师。

通知原文：
【粘贴通知原文】
```

## 输出示例

| 事项 | 来源 | 截止 | 对象 | 交付 | 负责人 | 优先级 |
|---|---|---|---|---|---|---|
| 交军训免训证明 | 辅导员 | 8.20 17:00 | 申请免训同学 | 纸质交办公室 | 班长 | 高 |

**待确认问题**：免训证明需要医院证明原件还是复印件？

## 注意
- 涉及同学姓名、学号、电话时：用「同学 A / 学号后四位」脱敏后再发在线 AI。
- 台账存本地（Excel/Notion/Obsidian 均可），不要只存在聊天记录里。
