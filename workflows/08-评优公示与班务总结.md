# 工作流 08 · 评优公示与班务总结

- **一句话用途**：把评优/推优/期末总结写成「规则公开、过程留痕」的规范文本。
- **适用场景**：军训优秀学员推荐、学期班务总结、评优公示、竞选复盘。
- **输入**：评选规则 + 记录数据 + 结果。
- **输出**：公示文案 + 总结报告 + 留痕清单。

## 提示词模板（复制即用）

```
你是班级事务文书助手。任务：【军训优秀学员推荐公示】。
- 评选规则：【粘贴规则】
- 参考记录：【考勤/表现记录，脱敏】
- 拟定结果：【名单】

请输出：
1. 「公示文案」：规则 → 过程 → 结果 → 异议渠道，语气公正；
2. 「过程留痕清单」：我应该保存哪些原始记录以备查（考勤表、加分项、会议记录等）；
3. 「异议应对话术」：若有同学质疑结果，我如何回应；
4. 「学期班务总结」框架：做了什么（数据）+ 解决了什么问题 + 下学期改进。
```

## 注意
- 评优是班长最高风险工作：任何结果都要「先公示规则，再公示结果，留原始记录」。
- 涉及自己利益的评选主动回避，请辅导员或班委代表裁定。
