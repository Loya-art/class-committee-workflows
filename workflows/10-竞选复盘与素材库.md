# 工作流 10 · 竞选复盘与素材库

- **一句话用途**：把做过的每一件小事，变成竞选演讲、月度复盘、保研/选调面试的素材。
- **适用场景**：每周复盘、正式竞选前、学期末、未来写简历/面试。
- **输入**：本周做过的事（流水账即可）。
- **输出**：可量化成果 + 故事版素材 + 面试式提炼。

## 提示词模板（复制即用）

```
你是班长成长记录助手。以下是我这周/这个阶段为班级做的事：
【粘贴流水账】

请输出：
1. 「可量化成果」：能写进竞选稿/总结的数字与事实（如：转发通知 N 条、收集材料 N 次、解决问题 N 件）；
2. 「一个故事」：从流水账里挑一件小事，改写成 80 字「困难—行动—结果」故事，用于演讲；
3. 「面试版素材」：用 STAR 结构（情境/任务/行动/结果）提炼 1 条，将来可用于保研、选调、评优面试；
4. 「下周改进」：2 条可执行改进建议。
```

## 输出示例（STAR）

- 情境：军训期间每天通知超过 5 条，同学经常漏看。
- 任务：保证全班 35 人零漏通知。
- 行动：建立通知台账 + 每晚固定「明日提醒」+ 重要通知私聊确认。
- 结果：军训期间零漏报，辅导员两次点名表扬。

## 注意
- 素材库每周只花 10 分钟维护，一年后就是你的「竞选用事实库」和「面试弹药库」。
- 记录要真实、留痕，别夸大数字——面试官会追问细节。
