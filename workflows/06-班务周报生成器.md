# 工作流 06 · 班务周报生成器

- **一句话用途**：每周日晚 20 分钟，把一周班务变成一条让全班和辅导员都看得见的周报。
- **适用场景**：每周日晚固定发布。
- **输入**：一周通知台账 + 大事记 + 下周安排。
- **输出**：群周报（短）+ 给辅导员的汇报（正式）。

## 提示词模板（复制即用）

```
你是班长周报助手。以下是我这周的工作记录：
【粘贴本周台账/大事记，建议脱敏】

请生成两个版本：
1. 「班群周报」：≤150 字，分「本周办了什么 / 下周提醒 / 一句感谢」，语气温暖；
2. 「辅导员汇报版」：分「已完成 / 进行中 / 需要老师支持」三点，正式简洁，附 1 条建议。

同时给我 3 条「下周最可能漏」的风险提醒（截止日、易漏材料、可能冲突的活动）。
```

## 输出示例

📋【班级周报 · 第 3 周】
本周：完成军训评优材料收集、组织 1 次破冰活动 ✅
下周：9.8 前交体检表；周三班会（地点待定）
感谢每位同学的配合，下周继续加油 🙌

## 注意
- 周报是「信任资产」：坚持每周发，比任何竞选口号都有说服力。
- 给辅导员的版本别写流水账，只写「结果 + 需要什么」。
